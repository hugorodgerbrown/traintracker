Live GB train times in Claude and ChatGPT

Traintrackr is a connector that answers questions about National Rail trains: which platform, what is running late, and how to get from one station to another.

Things to ask

Which platform is the next train from Cambridge to Kings Cross?

What are the next trains from Liverpool Street to Colchester, and are they on time?

How do I get from Cambridge to Sudbury on Saturday morning?

The docs show what each answer contains, and what Traintrackr can't tell you.

The same question, without and with it

Without a connector, Claude searches the web for departure boards. Most of them load their times in the browser, so it can't read them.

Traintrackr is free to use. You sign in with an email address; there is no password.

Add it to Claude

  1. Open Settings, then Connectors, and choose Add custom connector.
  2. Give it the name Traintrackr and paste the connector address. Leave the OAuth fields empty.
  3. Choose Connect. Claude opens the Traintrackr sign-in page.
  4. Enter your email address, then the six-digit code sent to it.

Add it to ChatGPT

Traintrackr isn't in the ChatGPT directory yet. Until it is, ChatGPT can add it only in Business, Enterprise and Edu workspaces, using developer mode on the web. A workspace admin has to allow developer mode first.

  1. In ChatGPT, open Settings, then Apps, then Advanced settings, and turn on Developer mode.
  2. In Settings, then Apps, choose Create. Give it the name Traintrackr, paste the connector address and choose OAuth.
  3. ChatGPT opens the Traintrackr sign-in page. Enter your email address, then the six-digit code sent to it, and finish creating the app.
  4. In a new chat, choose Traintrackr from the tools menu.
